# Language Learning App

This is a fun and interactive Language Learning App! It works like a game where you learn new words, take quizzes, keep a daily streak, and earn gems and hearts.

## How to play this app on your computer:
1. Open this folder in **VS Code**.
2. Click **Terminal > New Terminal** at the top.
3. Type `npm install` and press Enter (you only need to do this once).
4. Type `npm run dev` and press Enter.
5. `Ctrl + Click` the link that says `http://localhost:5173/` to play!

## How to push this to GitHub using VS Code:
Here are the super simple steps to upload this project to your GitHub profile!

### Step 1: Create a GitHub Repository
1. Go to your GitHub account on the internet (github.com).
2. Click the green **"New"** button to create a new repository.
3. Name it `language-learning-app` (or whatever you like).
4. Do NOT check the "Add a README file" box (because you already have this one!).
5. Click **Create repository**.

### Step 2: Push from VS Code
1. Open this folder in **VS Code**.
2. Click **Terminal > New Terminal** at the top.
3. Type these commands one by one, and press Enter after each:
   * `git init`
   * `git add .`
   * `git commit -m "My first commit!"`
4. Now, look back at the GitHub page you just created in Step 1. Copy the code they give you that starts with `git remote add origin...` and paste it into your VS Code terminal, then press Enter.
5. Finally, type this command and press Enter:
   * `git push -u origin main` (or `git push -u origin master`)

That's it! Refresh your GitHub page and you will see your code online!
