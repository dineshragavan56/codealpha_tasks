 Random Quote Generator

Welcome to my Random Quote Generator! This is a simple, fun web project built as a beginner assignment. 

What does it do?
When you open this website, it shows you a random, inspiring quote. If you click the "Generate Next" button, the screen will smoothly change to show you a brand new quote. It has 30 different quotes built in!

Files in this Project
This project is built using the three core languages of the web:
- index.html : The structure of the page (the text and the button).
- style.css : The design of the page (the cool dark background, colors, and floating animations).
- script.js : The logic that makes the button work and picks the random quotes.
